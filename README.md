# Nitesh Jadhav Portfolio

A premium dark SaaS-style developer portfolio built with React, Tailwind CSS, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Customize

- Update email/social links in `src/App.jsx`.
- Add your profile photo as `public/Nitesh.png`.
- Replace resume mail links with a real file path after adding a resume to `public/`.
- Update project data in the `projects`, `thinking`, and `skills` arrays in `src/App.jsx`.
- Visual components live in `src/components/`.
